# 03 — Preparação de frontend

Leia instruções e plano. Execute somente após aprovação explícita do usuário, incorporando os ajustes informados. Se a aprovação estiver ausente, apresente o plano para revisão.

Atualize os documentos com as decisões. Atualize AGENTS.md do repositório autorizado preservando regras existentes, com padrões, checks, escopo, continuidade e limites de autorização. Evite instruções sobre arquivos inexistentes.

Prepare branch de migração conforme o estado Git, sem descartar alterações nem substituir branch existente automaticamente. Se houver alterações que tornem a operação insegura, registre a situação para decisão; não faça stash/reset por conta própria.

Registre a referência inicial, contratos originais, alterações alheias e primeira etapa no progresso. Confira links e consistência dos documentos.

Não implemente etapas, não faça commit ou push. Pare para o usuário revisar a preparação e depois autorizar o prompt 05.
