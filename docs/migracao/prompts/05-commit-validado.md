# 05 — Commit validado de frontend

Entrada obrigatória: confirmação do usuário de que validou a etapa, preparação ou revisão final, com identificação do escopo. Sem essa confirmação, não faça commit.

Leia instruções e progresso. Revise Git/diff e resultados dos checks. Inclua somente alterações do escopo validado. Não inclua alterações preexistentes alheias, segredos, logs ou artefatos ignorados; não use git add indiscriminadamente.

Atualize progresso com estado validado, pendências, versão de referência e próximo passo. Crie commit(s) locais coerentes com a unidade validada. Use o histórico Git para identificar o commit que contém o próprio registro, sem ciclo de commits para registrar seu hash.

Informe hashes, escopo e alterações que permaneceram fora do commit. Não faça push, deploy nem inicie outra etapa.
