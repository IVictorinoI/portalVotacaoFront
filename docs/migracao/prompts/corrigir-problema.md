# Corrigir problema na migração de frontend

Entrada: etapa, cenário, passos para reproduzir, esperado e obtido. Leia instruções e registros da etapa. Reproduza quando possível; registre o que não conseguiu verificar.

Investigue a causa e corrija no repositório autorizado, dentro do escopo aprovado. Verifique outros fluxos afetados pela mesma causa e acrescente teste de regressão quando adequado. Não enfraqueça contratos ou remova funcionalidades para esconder o defeito.

Se a causa estiver no outro projeto, registre a evidência para uma correção separada; não o altere. Atualize checkpoint, execute verificações e forneça roteiro para nova validação.

Não faça commit nem avance para outra etapa. Pare para revisão.
